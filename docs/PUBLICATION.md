# 公开仓库包含哪些内容

仓库提供平台源码、锁定依赖、8 个自带示例 Skill、测试、运行脚本、接口与设计文档，以及经过检查的演示图片和视频。

以下内容不进入公开快照：

- `data/` 中的账号哈希、签名密钥、OAuth 授权、会话、票据、审计与上传包。
- `.env`、客户端全局配置、个人目录和本地备份。
- 原始录屏、会话导出、完整客户端调用日志和本机安装目录。
- 案例中用户另外上传的第三方技能包。

公开演示账号和密码是 PoC 测试数据，运行时仍使用密码哈希。新部署应从种子数据启动，不需要复制发布者的数据目录或客户端凭据。

文档中的个人绝对路径已替换为项目目录占位符；公开图像聚焦演示账号、工具与业务结果，个人账户区域和本机路径不在展示范围。公开视频仅说明工具用途。

`scripts/check_publication.py` 检查受 Git 管理的文件，拒绝运行数据、个人主目录路径和常见凭据特征。图片和视频另经代表帧人工检查；模式检查不能替代对新增素材的审阅。
