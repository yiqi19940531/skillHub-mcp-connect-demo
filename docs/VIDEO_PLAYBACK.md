# 演示视频播放

[打开播放器](https://yiqi19940531.github.io/skillHub-mcp-connect-demo/)

README 使用 GIF 展示循环短预览，点击后进入 GitHub Pages 的 HTML5 视频播放器。静态封面链接只会显示一张图片，仓库文件页也不是稳定的完整播放入口，因此不再作为主要入口。

播放器支持播放/暂停、重新播放、前进/后退、拖动进度、全屏和 0.75～2 倍速选择。默认 1×；切换演示时暂停上一段。MP4 下载是备用入口。

视频为 1920×1080、H.264 Main Level 4.1、yuv420p、30 fps，MP4 的索引放在文件前部便于网页加载。长时间无变化的等待已缩短，字幕保留阅读时间。Qoder 案例使用已有对话画面作聚焦展示，再接真实 Web 审核过程，未重新执行安装、上传或审批。

## 托管

GitHub Pages 从 `main` 分支的 `/docs` 发布。`docs/.nojekyll` 让 HTML、CSS、JavaScript 与视频按静态文件直接提供。项目改名时，需要同步 README 与播放器的仓库/站点地址。

本地可使用支持 HTTP Range 的静态文件服务检查视频。完整播放、进度跳转和变速在浏览器中验证；仅用 FFmpeg 解码不能证明网页播放器交互正确。
